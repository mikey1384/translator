# Security policy

## Supported versions

Security fixes are made against the current release line. Users should update to the newest signed Translator release available from [translator.tools](https://translator.tools/#all-downloads).

## Report a vulnerability privately

Do not open a public GitHub issue for vulnerabilities involving:

- API keys, authentication, or secure storage;
- payment, credits, entitlements, or checkout fulfillment;
- update delivery, signing, notarization, or release artifacts;
- arbitrary file access, command execution, or unsafe media handling;
- disclosure of private user data or content.

Email **mikey@stage5.tools** with:

- a concise description and affected version;
- platform and CPU architecture;
- reproduction steps or a minimal proof of concept;
- realistic impact;
- any suggested mitigation;
- whether the report may be acknowledged publicly after a fix.

Please avoid accessing other people's data, disrupting services, testing against accounts you do not own, or publishing details before a fix is available.

## Ordinary bugs

Crashes and reproducible product defects without a security impact can be reported through [GitHub Issues](https://github.com/mikey1384/translator/issues).
